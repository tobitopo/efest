# Seguridad

## Estado del proyecto

Efest está en **pre-alfa**: no hay código, no hay auditoría y no hay versiones soportadas. No uses contraseñas reales ni datos que te importen.

## Reportar una vulnerabilidad

**No abras un issue público.** Usa el reporte privado de GitHub:

1. Entra en la pestaña **Security** del repositorio.
2. Elige **Report a vulnerability**.
3. Describe el impacto, los pasos para reproducirlo y, si puedes, una prueba de concepto.

No incluyas contraseñas, llaves, tokens ni datos personales reales en el reporte. Si necesitas compartir un archivo de bóveda, genera uno de prueba.

Acusaremos recibo lo antes posible y coordinaremos contigo la divulgación. Como el proyecto aún no tiene versiones publicadas, no hay una matriz de versiones soportadas.
